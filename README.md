## 🚀 소개

- 💾 **REST API 설계 및 서버 로직 구현** 

- 🧩 **데이터 처리 및 비즈니스 로직 구현
(더미 데이터 생성, Stored Procedure, 배치 처리)**

- 🗂️ **도메인 요구사항을 반영한 DB 설계 및 관계 모델링**

- 🐧 **쿼리 성능 개선 및 DB 최적화
(Index 설계, 실행 계획(EXPLAIN) 기반 튜닝)**

- 🧠 **시스템 안정성을 고려한 트랜잭션 및 동시성 처리 학습
(데이터 정합성, 원자성, 무결성 중심 설계)**

- 🔐 **사용자 권한(Role) 기반 기능 분리 및 데이터 구조 설계**

- 🌐 **프론트엔드와의 연동을 고려한 데이터 흐름 및 요청/응답 구조 이해**

- ⚙️ **데이터 정합성과 성능을 우선하는 백엔드 개발 지향**
